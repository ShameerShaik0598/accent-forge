# AccentForge

AccentForge is a mobile-first PWA for Indian English speakers learning British Received Pronunciation through structured lessons, reference audio, recording practice, and AI-assisted coaching feedback.

## Phase 1

This scaffold sets up the Next.js app shell, basic PWA metadata, and initial app routes:

- `/`
- `/home`
- `/lessons`

Lesson content, audio recording, AI feedback, and progress storage are intentionally postponed to later phases.
